# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a primary school Bahasa Melayu teacher, I want to upload a photo or PDF of this week's classroom worksheet, so that my struggling students can practise reading the exact material taught in class. (Connects to FR1, FR2)
   - Acceptance 1: Uploading a valid .jpg, .png, or .pdf file extracts the printed Malay text into an editable preview box within 5 seconds.
   - Acceptance 2: The extracted text is automatically split into numbered sentences for reading practice.

2. As a 7 year old child learning to read, I want to listen to a clear voice read a sentence first and then read it aloud myself, so that I can learn how to pronounce difficult Malay words confidently. (Connects to FR3, FR4)
   - Acceptance 1: Clicking "Dengar Contoh" plays a clear, slow Malay TTS audio recording of the current sentence.
   - Acceptance 2: After recording, the screen highlights correctly read words in green and mispronounced words in red.

3. As a parent, I want to view a simple progress report showing my child's reading speed and mispronounced words, so that I know which specific Malay words to revise with them at home. (Connects to FR5)
   - Acceptance 1: Completing a passage generates a summary screen showing accuracy percentage and reading speed (Correct Words Per Minute).
   - Acceptance 2: All incorrect words are listed in a "Perkataan Perlu Latihan" (Words to Practise) table with a replay button.
